Race Log · Add a race

1 · Get the CSV

Open the race on the iRacing results page and use its export button. You get a file named eventresult_<subsessionid>_0.csv. This is the one step that can't be automated — downloading it needs your logged-in iRacing session.

2 · Drop it here

Drop CSV files here or click to choose — you can add a whole season at once

3 · Publish

Save the updated file and commit it, or let this page push it to GitHub for you.

GitHub token setup (one time)
Create at github.com/settings/personal-access-tokens — scope it to only the opmo-race-log repo with Contents: Read and write. Nothing else.
Stored in this browser's localStorage on this machine only; never sent anywhere but github.com. Revoke it any time from the same settings page.
